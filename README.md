## 🧑‍💻 Tech Stack Used
**Frontend:** React.js, Tailwind CSS, Vite  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (Mongoose)  
**Authentication:** Firebase / JWT  
**Hosting:** Render (Frontend) + MongoDB Atlas (Database)

---

## 🚀 Features Implemented
- User Authentication (Sign up / Login with Google & Email and Forgot Password Feature)  
- Student Dashboard with Courses (To enroll or buy them and submit assignment) 
- Educator to track students participation and manage course content  created by them 
- AI search by text or voice among the courses, in multiple language
- Educator traking the number of participants enrolled in their course and number of courses and lectures created.
- Enabling Filtering of courses
